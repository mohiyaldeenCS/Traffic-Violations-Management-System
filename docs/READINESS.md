# حالة الجاهزية
## يعمل في حزمة التقييم
مصادقة cookie + CSRF + throttling، MFA TOTP مشفر اختياري ومحفوظ في Redis الإنتاج، عزل جهة، دور واحد لكل مستخدم، تسجيل مخالفة، دليل خاص SHA256 وحيازة، خطوات تسجيل/مراجعة/اعتماد/إصدار، اعتراض بقرار مسبب، تسوية مالية يدوية، محاكاة دفع معلنة، سلسلة تدقيق، import قديم آمن، API موثق، واجهة عربية.
## لا يُعتمد للإطلاق الحكومي
- بوابة هوية، مزود دفع/بنك/رسائل، كاميرا فعلية أو ANPR: غير متصلة.
- اعتماد اللوائح ومدد التظلم والعملة وملكية المركبة: تحتاج الجهة المالكة.
- الأدلة: تخزين ملفات محلي لا يحقق WORM/AV/KMS؛ مفتاح توقيع/anchor خارجي ليس مفعّلًا.
- MFA وإجراء استرداد/تعطيل يتطلب إجراءات تشغيل متفقًا عليها. حساب provision command محلي.
- لا اختبارات حمل ملايين السجلات، لا اختبار اختراق مستقل، لا DAST ولا مراجعة امتثال ASVS.
- تمرين استعادة محلي مع بصمات متطابقة نجح؛ لم يثبت HA أو RPO/RTO أو النسخ المجدول واختبار الاستعادة في بنية الجهة.
- لا تكامل مدفوعات فوري؛ finance يسجل مرجعًا تحقّق منه خارج المنصة.
- لم تجرِ مراجعة وصول/حفظ بيانات مع مستشار قانوني أو مسؤول بيانات.
المسار: موافقة الجهة على قواعدها وهويتها → أمان وخصوصية/قانون → خدمات حقيقية بعقود → S3 WORM وKMS/MFA/AV → staging → حمل/DAST/اختراق/Restore/HA → مراجعة تشغيلية مستقلة.
