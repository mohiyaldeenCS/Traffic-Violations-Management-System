# متطلبات المنتج
المستخدمون: مسجل المخالفات، المراجع، المعتمد، المحصل، مسؤول الاعتراض، المدقق، مدير الجهة، المواطن.
النتيجة المستهدفة: سجل قضية كامل يمكن تتبع مصادره وقراراته ومبلغه ومالكه من الرصد إلى الإغلاق.
القيمة: تقليل الأخطاء والتكرار وكشف التفويض غير الصحيح قبل توسيع الأحمال.
لا تُفترض قوانين أو عملات أو مدة اعتراض لبلد بعينه. القواعد والمؤقتات قابلة للإعداد وتعتمد من جهة مختصة.
الإصدار الأول للاختبار المؤسسي ببيانات صناعية، وليس ترخيصًا لإنفاذ مخالفات حقيقية.

## رحلة الموظف
تسجيل مركبة/مالك متحقق → إنشاء مخالفة بقانون مكوّن → إرفاق أصل الدليل → إرسال للمراجعة → مراجع مستقل → معتمد مستقل → إصدار وإشعار → اعتراض أو تحصيل → إغلاق.
## رحلة المواطن
حساب موثق خارج المنصة أولًا → الاطلاع على سجلاته فقط → دليل مصرح به → اعتراض ومتابعة القرار أو متابعة إيصال التحصيل. بوابة الدفع الحقيقية تتطلب عقدًا ومفاتيح؛ لا تحصيل بطاقات داخل المنصة.
