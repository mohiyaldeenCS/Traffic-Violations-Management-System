# المتطلبات ومعايير القبول
| ID | المتطلب | الأولوية | الاعتماد | معيار القبول وطريقة التحقق |
|---|---|---|---|---|
| ID-01 | جلسة وCSRF وMFA | P0 | هوية جهة | رفض طلب بلا CSRF/OTP واختبار replay |
| TEN-01 | عزل الجهات والمالك | P0 | ID-01 | IDs لجهة/مالك آخر تعيد 404 في API |
| ENF-01 | حالات وفصل مهام | P0 | TEN-01 | لا يعتمد منشئ القضية قضيته، حالات غير قانونية 400/409 |
| ENF-02 | منع تكرار/version | P0 | ENF-01 | مرجع المصدر فريد، رفض version قديم |
| EVD-01 | أصل وSHA256 وحيازة | P0 | ENF-01 | download يعيد الأصل، التلف يمنع الإصدار والتنزيل |
| FIN-01 | تحصيل ذري | P0 | ENF-01 | مبلغ مطابق وعملة مطابقة ومرجع فريد وidempotency |
| APP-01 | اعتراض وقرار | P1 | ENF-01 | مالك فقط يقدم، مسؤول مستقل يحكم مع السبب |
| DEV-01 | أجهزة وأحداث | P1 | TEN-01 | معرف الحدث يمنع replay، محاكي صريح |
| AUD-01 | تدقيق append-only | P0 | TEN-01 | المستخدم العادي لا يكتب/يمحو السجل؛ سلسلة قابلة للتحقق |
| OPS-01 | نشر واستعادة | P1 | جميع الوحدات | migrations وhealth واختبار restore على قاعدة منفصلة |
| UI-01 | RTL/keyboard | P1 | API | desktop/mobile واختبار رحلة حقيقية بالمتصفح |
| PERF-01 | قياس أحمال | P2 | PostgreSQL | تقرير p95 وحجم بيانات وعتاد؛ لا ادعاء ملايين مثبت |

أهداف أولية غير مضمونة: p95 قراءة أقل من 500ms عند 50 مستخدمًا نشطًا و100 ألف قضية، توافر 99.9%، RPO 15 دقيقة وRTO ساعتان. لا تصبح SLA قبل اختبار حمل واستعادة وHA في البنية المستهدفة.
