# ADR-0001 — منصة معيارية قابلة للاختبار
التاريخ: 2026-10-11. الحالة: مقبول للتنفيذ الأول، قابل للمراجعة مع الفريق المشغل.

## المقارنة
| الخيار | المعاملات والأمن | التشغيل والصيانة | تكلفة الهجرة | القرار |
|---|---|---|---|---|
| Laravel 13 + Inertia/React | ORM وسياسات وطوابير متكاملة؛ تحديثات أمنية حتى مارس 2028 | PHP 8.3+ وComposer؛ غير مثبتين هنا | منخفضة لغويًا لكن الحالي لا يحوي منطق أعمال قابلًا للنقل | بديل قوي خصوصًا لفريق PHP |
| ASP.NET Core 10 | Identity وأنواع ثابتة ومعاملات؛ LTS حتى نوفمبر 2028 | runtime متاح، Linux مدعوم؛ كتابة طبقة الأعمال وORM | إعادة تنفيذ مماثلة | مناسب لفريق C# |
| Django 5.2 LTS + DRF | جلسات وCSRF وORM وترحيلات ومعاملات ومكتبات ناضجة | Python متاح؛ دعم ممتد حتى أبريل 2028 | إعادة تنفيذ محدودة لأن القديم ثلاثة endpoints فقط | **مختار** |
| FastAPI | OpenAPI قوي؛ يحتاج تجميع المصادقة والإدارة والترحيلات | جيد لخدمة الرؤية المستقلة | عمل إضافي لبناء الحوكمة | موصل معالجة اختياري مستقبلًا |
| NestJS | TypeScript ووحدات وGuards؛ يلزم اختيار ORM/identity | توحيد اللغة مفيد | لا توجد شيفرة TS قديمة | بديل معتبر |

هذه تقديرات هندسية وليست benchmark أداء أو تكلفة مقاسة؛ لا نملك معلومات توظيف الفريق أو ميزانية الاستضافة. أفضلية Django هنا ناتجة عن سرعة بناء واختبار قواعد العزل والمعاملات والمهاجرات، لا عن عجز Laravel. غياب PHP المحلي عامل ثانوي وليس سبب القرار الوحيد.

## الواجهة
React + TypeScript + Vite: بوابتان محميتان دون حاجة SEO أو SSR، يقلل خادمًا إضافيًا مقارنة Next.js.
Vue/Nuxt مكافئ وظيفيًا مع خبرة فريق مناسبة؛ Angular يوفر conventions أشد لكنه أثقل لهذه المرحلة. Inertia مناسب عند اختيار Laravel فقط.

## البيانات
PostgreSQL هو هدف الإنتاج: قيود وأقفال صفوف وفهارس، وإضافة PostGIS مستقبلًا. MySQL مقبول لكنه لا يقلل تكلفة نقل النموذج القانوني. SQLite للتطوير والاختبارات السريعة فقط، ولا يثبت سلامة التزامن الإنتاجي. Redis اختياري للحد من المعدلات المشترك؛ outbox في PostgreSQL للأحداث الذرية. واجهة تخزين خاصة قابلة لاستبدال local بـS3؛ لا روابط عامة للأدلة.
